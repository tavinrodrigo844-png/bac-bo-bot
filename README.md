# Baccarat Bot
Bot de Telegram para análise de resultados de Baccarat

## 🚀 Como usar:

### Comandos:
- `/start` - Menu inicial
- `/add_result [B/P/T]` - Adicionar resultado
  - B = Banco venceu
  - P = Jogador venceu
  - T = Empate
- `/stats` - Ver estatísticas
- `/clear` - Limpar histórico
- `/help` - Ajuda

### Exemplo:
```
/add_result B
/add_result P
/add_result T
/stats
```

## 📊 Funcionalidades:

- ✅ Registrar resultados de Baccarat
- ✅ Calcular porcentagem de vitórias
- ✅ Histórico de resultados
- ✅ Estatísticas em tempo real

## 🔧 Instalação Local:

```bash
pip install -r requirements.txt
python main.py
```

## 🌐 Deploy no Render:

1. Conecte seu repositório GitHub
2. Configure a variável `BOT_TOKEN`
3. Deploy automático!
